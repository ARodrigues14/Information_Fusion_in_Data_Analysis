# Information Fusion in Data Analysis

Course projects for *Information Fusion in Data Analysis* (FIAD), Department of Informatics Engineering, University of Coimbra, 2024/2025.

**Authors:** Afonso Rodrigues · Emanuel Pacheco

| Project | Topic | Methods |
|---|---|---|
| [Project 1](Project1/) | Robot localization by fusing speed, gyroscope and GNSS data | Extended Kalman Filter, Unscented Kalman Filter, dead reckoning |
| [Project 2](Project2/) | Deciding whether to buy life insurance by fusing personal, health, financial and expert-rule information | Naive Bayes classifier implemented from scratch |

Each folder has its own README with the problem, the method, the results and instructions for running it.

Both projects are Jupyter notebooks written in Python and use NumPy, matplotlib and scikit-learn. Project 1 also uses SciPy, and Project 2 uses pandas.
